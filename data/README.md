# Benchmark subset

This directory contains the four E-VRP-NL instances required by the C++ test
suite. They are unchanged members of the public 120-instance benchmark created
by Montoya et al. (2017).

These XML files are third-party research data. They are not covered by the
project's BSD 3-Clause License and are not relicensed by this repository. Refer
to VRP-REP for the dataset's source information and applicable terms.

- Dataset: <https://www.vrp-rep.org/datasets/item/2016-0020.html>
- VRP-REP ID: `2016-0020`
- Reference: A. Montoya, C. Guéret, J. E. Mendoza, and J. G. Villegas, “The
  electric vehicle routing problem with nonlinear charging function,”
  *Transportation Research Part B: Methodological*, 103, 87-110, 2017.
  <https://doi.org/10.1016/j.trb.2017.02.004>

The full benchmark is intentionally not duplicated in this minimal source
release.
